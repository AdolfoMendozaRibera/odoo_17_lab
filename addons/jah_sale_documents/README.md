# JAH - Mejoras Documentos de Venta

Módulo de personalización de documentos de venta para JAH en Odoo 17 Community.

## Características

- Encabezado unificado de 3 cm
- Información de cliente estandarizada
- Descuentos visibles en tabla
- Firmas en órdenes de venta

## Instalación

1. Copiar módulo a addons
2. Actualizar lista de aplicaciones
3. Instalar módulo
